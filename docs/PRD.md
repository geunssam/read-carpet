## v2.1 추가: 도서관 로비 (게임처럼 돌아다니는 구조)

앱을 열면 **픽셀 탑뷰 도서관 로비** 정문에서 시작한다. 캐릭터가 방향키(또는 WASD, 화면 방향 단추)로 걸어 다니며 문 앞에 서서 들어간다.

| 장소 | 위치 | 들어가면 |
|---|---|---|
| 내 서재 | 뒷벽 왼쪽 문 | 내 미니홈피 (미니룸, 내 서재, 문장 책장) |
| 독서 아레나 | 뒷벽 가운데 큰 문 (레드카펫 끝) | 아레나 대결 |
| 꾸미기 가게 | 뒷벽 오른쪽 창구 | 상점 |
| 책 광장 | 왼쪽 게시판 | 카테고리, 도서 페이지, 리뷰, 자유 광장 |
| 안내 데스크 | 오른쪽 데스크 | 그 자리에서 출석 도장(숙련도 +5) |

- 조작: **지도를 누르면 그 자리까지 걸어간다**(막힌 곳을 누르면 가장 가까운 빈 칸까지). 문 이름표를 누르면 그 문 앞까지 간다. 컴퓨터에서는 방향키·WASD로 한 칸씩도 걸을 수 있다. 문 앞 발판에 서면 안내 카드가 뜨고 Enter 또는 단추로 입장한다.
- 화면 방향 단추와 아래 탭 메뉴는 없앴다(근쌤 결정). 모든 이동은 로비에서 한다.
- **문을 열면 모달(창)이 로비 위에 뜬다.** 화면이 바뀌지 않아서 돌아오기 쉽다. Esc, 바깥 누르기, "로비로" 단추로 닫으면 로비의 같은 자리로 돌아온다. 창이 열려 있는 동안은 걷기가 멈춘다. 창 안에서 "이 책으로 아레나"처럼 다른 곳으로 가는 단추는 창 안에서 내용이 바뀐다.
- 지도 규격: 15칸 x 11칸, 한 칸 32px. 상세는 `docs/LOBBY_SPEC.md`.
- 시트 04 "서비스 진입 스프라이트"는 로비 입장 연출로 이어 간다.

> 시트에는 이 방식이 적혀 있지 않다(근쌤 요청, 11/7). 팀 합의 후 시트 02·03·04에 옮길 것.

## 01. 누구의 어떤 문제를 풀까요?

### 서비스 한 문장
당신의 책장에서 먼지만 쌓이던 고전 문학, 함께 읽으며 박수받고 레드카펫의 주인공이 되다.

### 사용자
혼자서는 고전이나 두꺼운 책(벽돌책)을 끝내지 못하는 20대 여성. 나의 책 취향을 알고 싶고, 그 취향을 SNS에 공유하고 싶다.

### 지금의 불편 (실제 장면)
쇼츠에서 본 고전 소설이 궁금해서 샀지만 30쪽에서 멈췄다. 책장에 꽂아 두고 사진만 찍어 올렸다. 읽었다고 말하기엔 찔리고, 그냥 두기엔 아깝다. 다른 사람은 이 책을 어떻게 읽었는지 궁금하다.

### 지금 쓰는 방법과 아쉬움
| 지금 쓰는 것 | 좋은 점 | 아쉬움 |
|---|---|---|
| 독서 기록 앱 (북적북적, 리더스 등) | 기록하면 책 탑이 쌓이고 캐릭터를 얻음. 리더스는 남의 기록을 보며 책을 찾음 | **이미 읽은 사람**의 기록 도구. 망설이는 사람을 시작하게 하지 못함. 꾸미기 보상은 혼자 보는 데서 끝남 |
| 함께 읽기 모임 (그믐, 힙독클럽 벽돌책 격파단 등) | 함께라서 끝까지 읽게 됨 | 정해진 시간·기간을 맞춰야 해서 진입 장벽이 높음. 독서 습관이 있는 사람 중심 |
| SNS 인증 (#책스타그램, #북스타그램) | 쉽게 뽐낼 수 있음 | 표지 사진만으로 인증되어 실제 독서와 이어지지 않음. 기록이 피드에 흩어져 취향이 쌓이지 않음 |

### 확인한 근거
| 종류 | 내용 |
|---|---|
| 인터뷰 | "고전 사두기만 하고 읽지 못했어요" |
| 자료 | 2025 국민 독서실태 조사(문화체육관광부): 성인 연간 종합독서율 38.5%, 2023년보다 4.5%포인트 감소. 전 연령 중 독서율이 오른 건 20대뿐(75.3%). 독서가 어려운 이유 1위 시간 부족, 다음이 다른 매체·콘텐츠 이용(성인 24.3%, 학생 19.1%). 책을 읽는 이유 1위 "재미있어서"(20.3%) → **게임처럼 재미있게 접근할 근거** |
| 자료 | 텍스트힙: 소수의 독서 문화가 젊은층에게 힙한 행위이자 지적 호기심을 채우는 수단으로 자리 잡음 |
| 관찰 | 독서전시화: 읽는 것보다 책을 소유하고 보여 주는 데 집중하는 현상 |

> 확인 필요: 독서실태 조사 수치의 원문 링크를 07 발표자료에 붙일 것.

## 02. 이번에 어디까지 만들까요?

### 사용자가 얻을 변화
- 사용 전: 사 둔 고전이 책장에 먼지만, 취향을 말할 근거가 없음
- 사용 후: 내 도서 취향을 찾고, 읽기 시작한 기록이 홈피에 쌓이고, 남들과 겨루며 책 자체에 관심이 생김

### 꼭 구현할 것
| 번호 | 기능 | 한 줄 |
|---|---|---|
| 1 | 내 캐릭터 꾸미기 | 템플릿 요소로 기본 캐릭터를 만들고, 숙련도로 꾸미기 요소를 산다 |
| 2 | 미니홈피 꾸미기 | 테두리·배경을 꾸미고, 읽기 시작한 책과 수집한 문장을 전시한다 |
| 3 | 광장·아레나 | 카테고리별로 책을 둘러보고, 도서 페이지에서 리뷰를 보고, 아레나에 참가한다 |

### 이번에는 하지 않을 것
- 실제 백엔드: 로컬 저장과 브라우저 캐시로 빠르게 개발, 예시 화면만 활용
- 실제 결제(현질): 화면에 "준비 중"으로만 표시
- 실제 다른 사용자: 미리 만든 예시 사용자로 대체

### 완료 기준
온보딩에서 캐릭터를 만들고 → 미니홈피가 동작하고 → 숙련도 시스템으로 다음 행동을 유도하고 → 책 포럼과 아레나 예시가 동작하면 완료.

## 03. 사용 흐름과 핵심 기능

### 사용 흐름
| 단계 | 내용 |
|---|---|
| ① 첫 진입 | 진입 연출(스프라이트) → 온보딩 → 기본 캐릭터 만들기 |
| ② 입력·선택 | **캐릭터 고르기만** (3종, 고르면 기본 취향·칭호가 정해지고 입장 선물 숙련도 30점). 책·문장 고르기는 뺌 |
| ③ 핵심 행동 | 캐릭터 꾸미기, 읽기 시작할 책 고르기 |
| ④ 결과 | 내 캐릭터와 미니홈피, 취향 기반 추천 |
| ⑤ 다시 방문 | 캐릭터를 꾸며 공유, 숙련도 점수 쌓기, 아레나 대결 |

### 선택한 아이디어와 이유
텍스트힙의 본질은 "읽고 싶다"보다 "뽐내고 싶다"에 가깝다. 하지만 독서를 배제하지 않는다. 가볍게 시작한 사람, 진짜 책을 읽고 싶은 사람, 어려운 책을 쉽게 접하고 싶은 사람을 모두 품는 나만의 공간을 만든다. v2에서는 여기에 **"함께 읽고 박수받는"** 경험을 더해, 혼자서는 못 끝내는 고전을 끝까지 가게 한다.

### 핵심 기능 상세
| | 기능 1. 내 캐릭터 꾸미기 | 기능 2. 미니홈피 꾸미기 | 기능 3. 광장·아레나 |
|---|---|---|---|
| 사용자 행동 | 예시 템플릿 요소 고르기. 이후 모은 숙련도로 꾸미기 요소 구입 (현질은 다음 단계) | 캐릭터 테두리·배경 꾸미기, 도서 숙련도 쌓기, 문장 수집(책장) | 카테고리별 책 둘러보기, 책 리뷰·포럼, 숙련도 대결 |
| 화면 반응·저장 | 기본 캐릭터 생성. 홈피에 취향 기반 도서 추천, 비슷한 취향의 홈피 추천 | 꾸미기 요소, 선택 도서 정보, 숙련도(누적·사용), 프로필 외부 공유, **남의 홈피에서 대결 신청**, 숙련도 숨기기 | 도서 페이지에서 리뷰·댓글을 보고, 흥미가 생기면 숙련도를 쌓고, 아레나 참여 선택 |
| 완료 확인 | 캐릭터 만들기·꾸미기가 동작 | 홈피 꾸미기 동작, 총숙련도 사용 동작, **숙련도 쌓기 시작한 책이 홈피에 표시** | 카테고리 페이지·도서 페이지 동작, **도서를 고르면 내 홈피에 추가**, 도서 페이지에서 아레나 참가 동작 |

### 새로 정리한 화면 이동 (v2)
```
광장 ─ 카테고리(고전 문학 / 인문·철학 / 에세이·시 / 벽돌책)
        └ 도서 페이지 ─ 리뷰·댓글 보기, 박수 보내기
                       ├ [내 서재에 담기] → 미니홈피 "읽는 중" 칸에 표시
                       └ [이 책으로 아레나] → 같은 책 사람과 대결
미니홈피(남의 것) ─ [대결 신청] → 아레나
```

### 숙련도 (v1 유지, 박수 추가 제안)
| 행동 | 점수 | 하루 상한 |
|---|---|---|
| 출석 체크 | 5 | 1 |
| 오늘의 추천 도서 확인 | 5 | 1 |
| 문장 수집 | 10 | 10 |
| 책 제목 맞히기 | 10 | 3 |
| 포럼 댓글 | 10 | 5 |
| 내 리뷰가 박수 받음 (제안) | 2 | 20 |
| 책 문장 인증샷 | 20 | 3 |
| 독후감 | 50 | 2 |
| 독서 행사 참여 인증 | 50 | 없음 |
| 아레나 승리 / 참가 | 30 / 5 | 5 / 없음 |

### 잘 안 될 때
| 상황 | 대응 |
|---|---|
| 입력 없음·검색 결과 없음 | 재치 있는 문장으로 안내 (예: "이 책은 아직 레드카펫에 오지 않았어요") + 비슷한 취향의 도서와 홈피 추천 |
| 페이지 로딩 지연 | 대표 브랜드 캐릭터가 화면 가운데를 걸어가는 연출. **8초 넘으면** 크롬 공룡 게임 같은 미니게임 시작 |
| 입력칸 데이터 로딩 지연 | 서버 오류 안내 + 다시 시도 단추, 입력값은 그대로 유지 |
| 중복 입력 | "이미 있어요"로 안내하고 기존 항목으로 이동 |
| 잘못된 입력 | 비슷한 입력 추천 (예: 책 제목 오타 → 가까운 제목 제안) |
| 새로고침·이탈 | 검색창은 검색 결과 유지. 꾸미기 요소 구매 중 저장이 실패하면 구매 전 상태로 되돌림 |

## 04. 화면 · 데이터 · 구현 기준

### 디자인 방향
| 느낌 1 | 느낌 2 | 느낌 3 |
|---|---|---|
| 픽셀 | 탑뷰 | 캐주얼하고 귀여움 |

- 참고: 싸이월드(미니룸), 무료 애셋 활용
- **제안 (로고와 맞추기)**: 로고는 고급스러운 평면 그림이고, 시트의 느낌은 픽셀·탑뷰다. 둘을 이렇게 나눠 쓰면 충돌하지 않는다.
  - 로고·제목·카드·단추: 로고처럼 단정하고 고급스럽게
  - 미니홈피 방(미니룸)과 캐릭터: 싸이월드처럼 위에서 내려다본 픽셀 그림

### 로고 (확정 애셋)
| 파일 | 쓰는 곳 |
|---|---|
| `docs/brand/logo-square.png` (정사각, 책 세 권 + 펼친 카펫 + 반짝이) | 앱 아이콘, 진입 화면, SNS 공유 이미지 |
| `docs/brand/logo-horizontal.png` (가로형, 책 + 말린 카펫) | 상단 머리줄, 발표자료 표지 |

- 로고 구성: 검정·아이보리 책 세 권이 버건디 카펫 위에 쌓여 있고 실버 반짝이가 붙음. 글자는 "Read"는 검정 굵은 세리프, "Carpet"은 버건디 기울임 세리프.
- 다음에 필요한 로고 애셋: 투명 배경 PNG·SVG, 어두운 바탕용(글자 밝은 색), 책 묶음만 떼어 낸 아이콘(32·180·512px).

### 색 (로고에서 측정)

### 팀의 차별점
기존 독서 앱은 **다 읽은 뒤** 기록하지만, Read Carpet은 **읽기 전 망설이는 순간**부터 시작한다. 문장 하나로 시작해 함께 읽고, 박수받고, 겨루는 재미로 고전을 끝까지 가게 한다.

### 기대하는 가치
- 가설: 읽기 전에 시작하게 하고, 남에게 보여 주고 겨루는 보상을 주면 고전을 끝까지 읽는 사람이 늘어난다
- 측정(시연 기준): 온보딩 완료율, "읽는 중"에 담은 책 수, 아레나 참여 횟수, 리뷰 박수 수

### 다음 단계
1. 실제 로그인과 저장 (파이어베이스)
2. 같은 책 함께 읽기 방, 실제 사용자 대결
3. 문장 → 이미지·쇼츠 만들기
4. 숙련도 쿠폰·제휴·책 구매, 꾸미기 유료 요소
5. 인증샷 검증, 독서 행사 연동

### AI 사용과 팀의 판단
- AI 도움: 기획서 정리, 예시 데이터, 화면 코드, 그림 초안
- 팀이 직접: 사용자 정의, 로고 디자인, 범위 결정, 저작권 확인, 모바일 검수
