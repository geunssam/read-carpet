# 도서관 로비 지도 약속 (그림 담당 코덱스 F와 클로드 공용)

지도는 가로 15칸 x 세로 11칸, 한 칸 32px, 전체 480x352. 왼쪽 위 칸이 (열 0, 행 0).
탑뷰(위에서 내려다본) 픽셀 도서관 로비. 그림은 `public/assets/lobby/lobby-bg.svg` 한 장.
`viewBox="0 0 480 352"`, 루트에 `shape-rendering="crispEdges"`, 4px 격자의 rect만 사용. 글자(text) 금지(이름표는 앱이 위에 올림).
색은 docs/CONTRACT.md 색 토큰 v2 라이트 값과 그 밝고 어두운 단계만. 금색·밝은 빨강 금지.

## 칸 배치 (그림이 이 자리에 정확히 그려져야 함)
| 무엇 | 열 | 행 | 모양 |
|---|---|---|---|
| 뒷벽 | 0~14 | 0~1 | 짙은 버건디-블랙 벽, 책이 꽂힌 벽장 느낌. 위쪽 가장자리에 몰딩 |
| 아래 벽 + 정문 | 0~14 | 10 | 아래 벽, 가운데 열 6~8에 나무 정문(바깥 빛) |
| 왼쪽·오른쪽 벽 | 0 / 14 | 2~9 | 얇은 벽(책장 옆면) |
| 바닥 | 1~13 | 2~9 | 크림(#F4EEE4)·아이보리(#EBE1CF) 체크 무늬 바닥 |
| 레드카펫 길 | 6~8 | 2~9 | 정문에서 아레나 문까지 이어지는 버건디 카펫, 양쪽 실버 줄무늬, 정문 쪽 끝에 술(프린지) |
| 내 서재 문 | 1~2 | 0~1 | 아담한 나무 문, 위에 작은 책 모양 간판(글자 없이 책 그림) |
| 아레나 문 | 6~8 | 0~1 | 크고 화려한 이중문, 양쪽에 실버 트로피 기둥, 버건디 휘장 |
| 꾸미기 가게 | 11~13 | 0~1 | 차양이 달린 작은 가게 창구, 진열된 모자·안경 그림 |
| 책 광장 게시판 | 3~5 | 4~5 | 바닥에 놓인 커다란 게시판 스탠드, 책 표지와 쪽지가 붙어 있음(앞쪽 아래가 밝게 보이게) |
| 안내 데스크 | 9~11 | 4~5 | 책상(카운터), 위에 책 더미와 스탠드. 뒤(행 3)에 사서가 설 자리를 비워 둠 |
| 왼쪽 책장 | 1~2 | 7~9 | 바닥에 놓인 책장 한 세트(위에서 보이는 모양) |
| 오른쪽 책장 | 12~13 | 7~9 | 같은 모양 한 세트 |
| 화분 | (4,9) (10,9) | | 작은 화분 두 개 |
| 문 앞 표시 | (2,2) (7,2) (12,2) (4,6) (10,6) | | 바닥에 은은한 실버 원 모양 발판(걸어가 서는 자리) |

걸어 다닐 수 있는 빈 바닥은 시안성을 위해 너무 복잡하게 그리지 말 것. 걷는 캐릭터(약 48px)가 보여야 한다.
