## 01. 누구의 어떤 문제를 풀까요?

### 서비스 한 문장
책을 다 읽지 않아도 좋아하는 문장 하나로 내 취향을 뽐내고, 문장을 모을수록 강해지는 캐릭터로 책 친구들과 겨루는 독서 미니홈피.

### 사용자
- 주 사용자: 책에 관심은 있지만 완독이 부담스러운 10대 후반~30대
- 부 사용자: 어려운 고전·인문학을 가볍게 맛보고 싶은 사람
- 확장 사용자: 아이부터 어른까지, 책을 좋아하든 싫어하든 "지적인 나"를 드러내고 싶은 모든 사람

### 지금의 불편 (실제 장면)
서점에서 예쁜 표지의 책을 사서 사진은 올렸는데, 정작 세 장 읽고 덮었다. 책을 좋아한다고 말하고 싶지만 "뭐 읽었어?"라는 질문이 두렵다. 독서 앱은 완독 기록부터 요구해서 시작조차 못 한다.

### 지금 쓰는 방법과 아쉬움
| 지금 쓰는 것 | 아쉬움 |
|---|---|
| 인스타그램 책 사진 | 뽐낼 수는 있지만 책 내용과 연결이 없고, 다시 돌아올 이유가 없음 |
| 독서 기록 앱 (밀리의서재, 북플 등) | 완독·독후감 중심이라 진입 장벽이 높고, 재미 요소가 없음 |
| 유튜브 책 요약 | 소비만 하고 내 것이 되지 않음 |

### 확인한 근거
- 해커톤 주제 발표: "독서를 통해 나의 취향과 정체성을 표현" — 표현 욕구가 주제의 첫 항목
- 팀 토론 결론: 텍스트힙의 본질은 독서 욕구보다 과시 욕구. 단, 독서를 배제하지 않고 가볍게 시작해 진짜 독서까지 이어 주는 공간이 필요하다
- (확인 필요) 2030 독서율·"텍스트힙" 검색량 추이 자료

## 02. 이번에 어디까지 만들까요?

### 사용자가 얻을 변화
- 사용 전: 책은 사고 싶지만 읽기는 부담, 취향을 설명할 말이 없음
- 사용 후: 문장 몇 개로 내 취향이 캐릭터와 홈피로 보이고, 책 친구와 겨루면서 자연스럽게 책을 더 찾아보게 됨

### 꼭 구현할 것 (핵심 기능 3개)
| 번호 | 기능 이름 | 한 줄 설명 |
|---|---|---|
| 1 | 내 캐릭터 꾸미기 | 고른 책·문장으로 캐릭터가 만들어지고, 숙련도로 꾸미기 요소를 산다 |
| 2 | 미니홈피 꾸미기 | 수집한 문장이 책장이 되고, 테두리·배경으로 홈피를 꾸민다 |
| 3 | 광장·아레나 | 책 광장에서 포럼을 보고, 아레나에서 문장 카드로 1:1 숙련도 전투를 한다 |

### 이번에는 하지 않을 것
- 실제 백엔드·회원가입: 브라우저 저장소(로컬스토리지)만 사용
- 문장 → 이미지·영상(쇼츠) 자동 생성: 다음 단계
- 현질(실제 결제), 쿠폰·제휴, 숙련도로 책 구매: 다음 단계
- 인증샷 진위 검증: 올리기만 되고 검증은 없음
- 실제 다른 사용자: 미리 만든 가짜 사용자 4명으로 대체

### 완료 기준
온보딩 → 캐릭터 생성 → 미니홈피에서 문장 수집 → 숙련도 적립 → 꾸미기 요소 구입 → 책 광장 포럼 보기 → 아레나 전투 1판 승리 → 뺏어 온 문장이 내 책장에 들어오는 것까지 끊김 없이 되면 완료.

## 03. 사용 흐름과 핵심 기능

### 사용 흐름
| 단계 | 화면 | 사용자가 하는 일 | 화면 반응 |
|---|---|---|---|
| ① 첫 진입 | 온보딩 | 시작 단추 누르기 | 3단계 온보딩 시작 |
| ② 입력·선택 | 온보딩 1~3 | 책 3권 고르기 → 마음에 드는 문장 3개 고르기 → 캐릭터 요소 확인 | 고른 책·문장에 따라 캐릭터 색·장식·칭호가 자동 추천됨 |
| ③ 핵심 행동 | 미니홈피 | 문장 수집, 꾸미기 요소 구입 | 책장에 문장 카드가 쌓이고 숙련도가 오름 |
| ④ 결과 | 미니홈피 | 내 캐릭터·책장·취향 추천 확인 | 취향 기반 도서 추천 3권, 비슷한 취향의 홈피 2곳 추천 |
| ⑤ 다시 방문 | 광장·아레나 | 출석, 오늘의 추천 도서, 전투 | 숙련도 적립, 전투 승리 시 문장 획득 |

### 선택한 아이디어와 이유
텍스트힙을 즐기는 이유를 솔직하게 보면 "읽고 싶다"보다 "뽐내고 싶다"가 앞선다. 그래서 진입은 꾸미기와 수집으로 가볍게 열되, 꾸미려면 결국 문장과 책을 건드려야 하게 만들었다. 가볍게 쓰는 사람, 진짜 책을 읽고 싶은 사람, 어려운 책을 쉽게 접하고 싶은 사람을 하나의 공간에 모으는 것이 목표다. 차별점은 "점수를 숨긴 채 문장 카드로 붙는 1:1 전투"다.

### 핵심 기능 상세

#### 기능 1. 내 캐릭터 꾸미기
- 사용자 행동
  - 온보딩에서 책 3권, 문장 3개를 고른다
  - 추천된 기본 캐릭터(색·장식·칭호)를 확인하고 일부를 바꾼다
  - 이후 상점에서 숙련도를 써서 꾸미기 요소(모자, 안경, 배경 효과, 칭호)를 산다
- 화면 반응·저장할 내용
  - 캐릭터 미리보기가 즉시 바뀜
  - 저장: 캐릭터 구성(요소 번호 목록), 보유 요소, 칭호
- 취향 → 캐릭터 규칙 (예시)
  | 고른 책 성향 | 캐릭터 색 | 칭호 |
  |---|---|---|
  | 고전 문학 위주 | 버건디 | 서재의 귀족 |
  | 과학·인문 위주 | 실버 | 냉철한 관찰자 |
  | 에세이·시 위주 | 블랙+금 | 밤의 낭독가 |
- 완료 확인: 온보딩을 끝내면 캐릭터가 미니홈피 상단에 보이고, 새로고침해도 유지된다

#### 기능 2. 미니홈피 꾸미기
- 사용자 행동
  - 문장 수집: 책 검색(또는 직접 입력) → 문장 입력 → 책장에 카드로 저장
  - 책 한 권에 문장 3개가 모이면 "읽은 책"으로 자동 승격
  - 테두리·배경·음악(없으면 생략) 선택
  - 실제 책 인증샷 올리기 (검증 없음)
- 화면 반응·저장할 내용
  - 책장에 문장 카드가 쌓이고, 숙련도 숫자가 오름
  - 홈피 상단에 "취향 기반 추천 도서 3권", 하단에 "비슷한 취향의 홈피 2곳"
  - 저장: 문장 카드(책 제목, 저자, 문장, 수집일, 카드 점수), 꾸미기 설정, 인증샷(파일은 저장 안 하고 미리보기만)
- 완료 확인: 문장 3개를 수집하면 숙련도가 오르고 추천 도서가 바뀐다

#### 기능 3. 광장·아레나
- 책 광장
  - 책 표지 격자 → 책을 누르면 책 포럼 페이지
  - 포럼: 평론·댓글 (가짜 사용자 글 4~5개 미리 채움), 내 평론 쓰기
  - 오늘의 추천 도서 1권 (확인하면 숙련도 적립)
- 자유 광장
  - 비슷한 취향의 홈피 구경, 인증샷 모아 보기
- 게임 광장 (아레나)
  - 간판 세우기: 내 캐릭터와 칭호를 걸고 도전자 모집
  - 1:1 전투 규칙
    1. 내 책장에서 문장 카드 3장을 고른다
    2. 상대(가짜 사용자)도 3장을 낸다
    3. 카드마다 숨겨 둔 점수를 비교해 3판 2선승
    4. 이기면 상대 문장 1장을 내 책장으로 가져온다 (화면 문구는 "복사해 오기")
  - 점수 숨기기: 내 숙련도는 홈피에서 숨길 수 있고, 전투에서만 공개됨
- 완료 확인: 전투 1판을 이기면 내 책장에 상대 문장 카드가 추가되고 숙련도가 오른다

### 숙련도(전투력) 체계
| 행동 | 점수 | 하루 상한 |
|---|---|---|
| 출석 체크 | 5 | 1회 |
| 오늘의 추천 도서 확인 | 5 | 1회 |
| 문장 수집 | 10 | 10회 |
| 책 제목 맞히기(제목 일부 가리기 퀴즈) | 10 | 3회 |
| 책 포럼 댓글 | 10 | 5회 |
| 책 문장 인증샷 | 20 | 3회 |
| 독후감(평론) 올리기 | 50 | 2회 |
| 독서 행사 참여 인증 | 50 | 제한 없음 |
| 아레나 승리 | 30 + 상대 카드 1장 | 5회 |
| 아레나 패배 | 5 (참가 보상) | — |

- 문장 카드 점수 = 수집 시 10 + 그 책으로 쌓은 활동 점수의 10%
- 쓰는 곳: 꾸미기 요소 구입(30~200), 칭호 구입(100~500)

### 잘 안 될 때
| 상황 | 안내와 다음 행동 |
|---|---|
| 입력 없음·검색 결과 없음 | "그 책은 아직 없어요. 직접 입력할까요?" → 제목·저자 직접 입력 폼으로 이동 |
| 요청 실패·재시도 | 로컬 저장이라 네트워크 실패 없음. 저장 실패 시 입력값을 유지하고 "다시 저장" 단추 표시 |
| 중복·잘못된 입력 | 같은 책·같은 문장은 "이미 책장에 있어요"로 막고 기존 카드로 이동. 문장은 10자 이상 300자 이하 |
| 새로고침·이탈 후 | 캐릭터, 책장, 숙련도, 꾸미기 설정, 전투 기록을 로컬스토리지에서 복원. 온보딩 중 이탈 시 마지막 단계부터 재개 |

## 04. 화면 · 데이터 · 구현 기준

### 디자인 방향
- 느낌 3개: 레드 카펫의 화려함 / 고전 서재의 묵직함 / 카드 게임의 손맛
- 참고 화면
  - 싸이월드 미니홈피: 내 공간을 꾸민다는 감각
  - 포켓몬 카드·하스스톤: 카드 대결의 긴장
  - 밀리의서재 책장: 수집의 만족감
- 글꼴·색·위계
  - 색: 레드 카펫 시상식 분위기. carpet-red(메인), velvet(헤더), trophy-gold(뱃지·별), spotlight(하이라이트), 바탕 surface-100/200, 글자 ink. 밝은 모드와 어두운 모드 두 벌 (상세 표는 docs/CONTRACT.md)
  - 글꼴: 제목은 세리프 계열(고전 느낌), 본문은 산세리프(가독성)
  - 위계: 제목 28px 이상 / 소제목 20px / 본문 16px / 안내 14px

### 핵심 화면 3개
| 화면 | 주요 동작 |
|---|---|
| 온보딩 | 책 고르기 → 문장 고르기 → 캐릭터 확인. 진행 막대 3칸 |
| 미니홈피 | 캐릭터 + 책장 + 숙련도 + 추천. 문장 수집 단추가 가장 크게 |
| 아레나 | 카드 3장 선택 → 뒤집기 연출 → 결과 → 카드 획득 |

### 모션
- 카드 뒤집기(아레나 결과 공개): 긴장감 연출
- 숙련도 숫자 올라가는 연출: 보상 체감
- 그 외 없음. "동작 줄이기" 설정이면 모두 즉시 전환

### 모바일 확인 목록
- 320·390·768·1440px에서 가로 넘침 없음
- 긴 책 제목(예: "데미안: 에밀 싱클레어의 젊은 날의 이야기")과 긴 문장 카드가 잘리지 않고 줄바꿈
- 터치 대상 44px 이상 (카드, 단추)
- 글자 200% 확대, 키보드 입력, 뒤로가기 동작
- 특히 확인할 긴 문구: 문장 카드 300자, 칭호 10자, 책 제목 40자

### 데이터
- 입력받는 정보: 별명, 고른 책, 문장, 캐릭터 구성, 평론, 댓글, 인증샷(미리보기만)
- 저장 위치: 브라우저 로컬스토리지. 설정 화면의 "내 기록 지우기"로 전부 삭제
- 저장 구조 (키 이름)
  | 키 | 내용 |
  |---|---|
  | rc_user | 별명, 캐릭터 구성, 칭호, 숙련도, 점수 숨김 여부 |
  | rc_shelf | 문장 카드 목록 |
  | rc_items | 보유 꾸미기 요소 |
  | rc_battles | 전투 기록 |
  | rc_daily | 오늘 한 행동과 횟수 (날짜 바뀌면 초기화) |
- 외부 연결: 없음. 책 목록·가짜 사용자·포럼 글은 모두 앱 안의 예시 데이터 파일
- 연결 상태: 완전 오프라인 동작
- 출처·불확실한 정보 표시: 예시 문장에는 책 제목·저자 필수 표기. 저작권 문제가 없도록 저작권 만료 고전(헤세, 니체, 톨스토이 등) 위주로 예시 데이터 구성

## 05. 직접 확인하고 기록하기

| 검수 | 해 본 행동·기대 결과 | 실제 결과 | 증빙 |

### 팀의 차별점
기존 독서 앱은 "읽은 뒤"에 기록하지만, Read Carpet은 "읽기 전" 문장 하나로 시작하고, 그 문장이 카드가 되어 친구와 겨루는 재미로 다시 돌아오게 한다.

### 기대하는 가치
- 가설: 완독 없이 문장만으로 시작하면 독서 앱 온보딩 이탈이 줄고, 전투 때문에 재방문이 생긴다
- 측정(시연 기준): 온보딩 완료율, 사용자당 수집 문장 수, 아레나 참여 횟수

### 다음 단계
1. 실제 백엔드와 로그인 (파이어베이스)
2. 문장 → 이미지·쇼츠 생성
3. 실제 사용자 간 전투와 간판
4. 숙련도 기반 쿠폰·제휴·책 구매
5. 인증샷 검증과 독서 행사 연동

### AI 사용·팀의 판단
- AI 도움: 아이디어 정리, PRD 초안, 예시 데이터 생성, 코드 작성
- 직접 확인: 범위 자르기 결정, 전투 규칙, 예시 문장 저작권 확인, 모바일 검수
