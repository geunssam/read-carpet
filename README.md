# Read Carpet (E11세기)

책 한 권 안 읽어도 문장 하나로 시작하는 독서 미니홈피. 해커톤 시연용 MVP (서버 없음, 브라우저 저장만 사용).

## 실행

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 배포용 빌드 (dist/)
```

## 시연 흐름 (2분)

1. 별명 입력 → 캐릭터 고르기 (온보딩 2단계) → 도서관 로비에서 시작
2. 로비 지도를 눌러 걸어가기(컴퓨터는 방향키도 가능) → 문 앞에서 들어가기 → 창이 열림, Esc로 닫기
3. 내 서재: 출석 체크, 문장 수집 (숙련도 +)
4. 꾸미기: 숙련도로 모자·안경·배경 구입 후 착용
5. 광장: 오늘의 추천 도서, 제목 맞히기, 책 포럼 평론·댓글, 자유 광장 구경
6. 아레나: 입문 상대에게 카드 3장으로 도전 → 이기면 상대 문장 복사해 오기

## 폴더

- `src/features/` 화면별 폴더 (onboarding, minihome, shop, plaza, arena)
- `src/storage/` 브라우저 저장소 (rc_user, rc_shelf, rc_items, rc_battles, rc_daily, rc_forum)
- `src/data/` 예시 데이터 (책 20권, 문장 60개, 가짜 사용자 4명, 포럼 글 5개, 상점 25개)
- `public/assets/` 캐릭터·홈피 그림(SVG)
- `docs/PRD.md` 기획서, `docs/CONTRACT.md` 개발 약속 (색 토큰, 데이터 모양)

## 알아둘 점

- 예시 문장은 원문이 아니라 책의 분위기를 새로 풀어 쓴 문장입니다. 화면에도 그렇게 표시합니다.
- 기록을 지우려면 내 홈피 맨 아래 "내 기록 지우기".
- 아레나 동점은 도전자가 이깁니다. 입문 상대는 처음 하는 사람도 이길 수 있게 점수가 낮습니다.
